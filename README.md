# Subatomic Sizeling 
An origin that lets you unlock a ridiculous amount of control over your own size.

This origin is a (much better) recreation of an origin I made last year that I no longer have the files for. Made for a friend <3

## Pros
### All Stages
- Use your primary and secondary to change size. This scales with the stage;
     - Stage 1: 32% - 305%
     - Stage 2: 11% - 930%
     - Stage 3: 2% - 1625%
- Permanent slow falling, and no fall damage (slow falling disables while sneaking)
### Stage 2+
- When at 30% size or below, you gain creative flight.
- <img width="20%" alt="flying in survival" src="https://github.com/user-attachments/assets/efdffcb5-ebaf-4f6a-916b-4c93215fa009" />
### Stage 3
- When at 1% size, you can phase through materials.
- <img width="20%" alt="phasing" src="https://github.com/user-attachments/assets/54d0046d-822d-420a-a761-fcc544dfdf14" />


## Cons
- Your hunger runs down 90% faster.
- You take 10% more damage from all sources
- You take an additional 15% more damage from fire sources (lava, campfires, etc).

## Passives
- When at 40$ size or below, you can right click any mob with an empty hand to ride it.
- <img width="20%" alt="riding" src="https://github.com/user-attachments/assets/7706f97b-1a85-4180-8b62-25e8214257da" />
- Your health scales with your stage;
    - Stage 1: 10hp (5 hearts)
    - Stage 2: 20hp (10 hearts)
    - Stage 3: 30hp (15 hearts)

## Stages
This origin has stages; by doing certain things, your stage increases and you unlock more of your powers (May take ~10s to activate);
- Unlock Stage 2: Go within 20 blocks of world height. 
- Unlock Stage 3: Go to an extremely cold biome.
Each stage unlock has particles and a sound effect, so if you don't experience either you may not be meeting the conditions.

These stages can be skipped around with commands. Use the following commands to set your origin to a certain stage;
- Stage 1: /origin set @s origins:origin dmaxfield:sizeling_stage_1
- Stage 2: /origin set @s origins:origin dmaxfield:sizeling_stage_2
- Stage 3: /origin set @s origins:origin dmaxfield:sizeling_stage_3

# Installation

Mod Dependencies
- Pehkui
- Origins
Other Notes:
- Made for and tested on 1.20.1 - fabric loader 0.19.2 (though neither should matter too much).

To install, launch an instance of Minecraft with the aforementioned mods, then follow the below instructions based on whether you're adding to a world or creating a new one.

For a new world: once in the world creation screen, go to More -> Data Packs -> Open Pack Folder. Drag the zip file release into the opened folder, then return to Minecraft, move the datapack to the "Selected" side, and continue with world creation.

For an existing world: Select the world in the Singleplayer world list, then click Edit -> Open World Folder, then open the 'datapacks' folder. Drag the zip file in there, and you're ready to load up the world.
